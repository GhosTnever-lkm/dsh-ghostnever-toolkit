# SemVer Bump

Increment major, minor or patch in a strict semantic version.

## Install

`sh
dsh plugin --profile web add "github:GhosTnever-lkm/dsh-ghostnever-toolkit#path:/packages/semver-bump"
`

Restart the selected profile after adding the bundle. This utility operates on the supplied arguments only; it does not access files or the network.
