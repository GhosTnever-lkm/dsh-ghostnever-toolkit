# Case Converter

Convert text between camel, Pascal, snake, kebab and title case.

## Install

`sh
dsh plugin --profile web add "github:GhosTnever-lkm/dsh-ghostnever-toolkit#path:/packages/case-converter"
`

Restart the selected profile after adding the bundle. This utility operates on the supplied arguments only; it does not access files or the network.
