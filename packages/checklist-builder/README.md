# Checklist Builder

Turn a list of tasks into a Markdown checklist.

## Install

`sh
dsh plugin --profile web add "github:GhosTnever-lkm/dsh-ghostnever-toolkit#path:/packages/checklist-builder"
`

Restart the selected profile after adding the bundle. This utility operates on the supplied arguments only; it does not access files or the network.
