# CSV Profiler

Inspect a CSV sample: dimensions, headers and empty cells.

## Install

`sh
dsh plugin --profile web add "github:GhosTnever-lkm/dsh-ghostnever-toolkit#path:/packages/csv-profiler"
`

Restart the selected profile after adding the bundle. This utility operates on the supplied arguments only; it does not access files or the network.
