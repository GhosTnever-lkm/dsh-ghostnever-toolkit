# Markdown Outline

Build a heading outline and table of contents from Markdown.

## Install

```sh
dsh plugin --profile web add "github:GhosTnever-lkm/dsh-ghostnever-toolkit#path:/packages/markdown-outline"
```
Restart the selected profile after adding the bundle. This utility operates on the supplied arguments only; it does not access files or the network.
