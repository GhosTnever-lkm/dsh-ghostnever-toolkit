# Text Hash

Calculate SHA-256, SHA-384 or SHA-512 for supplied text.

## Install

`sh
dsh plugin --profile web add "github:GhosTnever-lkm/dsh-ghostnever-toolkit#path:/packages/text-hash"
`

Restart the selected profile after adding the bundle. This utility operates on the supplied arguments only; it does not access files or the network.
